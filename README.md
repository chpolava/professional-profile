# Chetan P S — Professional Resume Website

A responsive, static professional portfolio built from the information in the supplied resume, plus the additional projects/interests provided by Chetan.

## Files

- `index.html` — main webpage
- `styles.css` — responsive visual design
- `script.js` — lightweight enhancement
- `assets/profile.jpg` — supplied professional portrait
- `Chetan-P-S-Resume.pdf` — supplied resume for download

## Free hosting

### Option 1 — GitHub Pages (recommended)
1. Create a public GitHub repository named `chetanps11.github.io` (or use any project repository).
2. Upload all files in this folder, keeping the `assets` folder intact.
3. In GitHub: **Settings → Pages → Deploy from branch → main → /root**.
4. GitHub will publish the site at `https://<your-github-username>.github.io/`.
5. A custom domain can be added later.

### Option 2 — Cloudflare Pages
Create a Pages project, connect the GitHub repository, and deploy the static files. Cloudflare Pages supports static HTML sites and has a free plan.
